# mcp-template

Substitua pelo que este servidor faz e para quem ele serve.

## Requisitos

- Node.js 20 ou mais recente

## Instalação

```json
{
  "mcpServers": {
    "template": {
      "command": "npx",
      "args": ["-y", "@rafaelltlins/mcp-template"]
    }
  }
}
```

## Configuração

Substitua pelas variáveis de ambiente ou remova esta seção.

## Ferramentas

| Ferramenta | O que faz | Custo |
| --- | --- | --- |
| `echo` | Retorna o texto informado | Grátis |

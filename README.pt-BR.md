# Servidores MCP

Uma coleção de servidores independentes de [Model Context Protocol](https://modelcontextprotocol.io) (MCP), documentados em inglês e português do Brasil. O MCP permite que assistentes de IA, como Claude Code, Claude Desktop e Cursor, usem ferramentas e serviços externos.

Cada servidor tem versão, dependências e documentação próprias, então você instala só o que precisa.

## Servidores

# MCP Servers

A collection of independent [Model Context Protocol](https://modelcontextprotocol.io) (MCP) servers, documented in English and Brazilian Portuguese. MCP lets AI assistants such as Claude Code, Claude Desktop and Cursor use external tools and services.

Each server has its own version, dependencies and documentation, so you only install what you need.
